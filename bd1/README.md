 # Бие даалт №1 сэдэв 13. Өвлийн хүйтэн

# яадаг програм бэ?

7 өдрийн температурыг (°C) оруулж, Фаренгейт (°F) руу хөрвүүлээд, хүйтний ангилал болон хувцасны зөвлөмж гаргаж, хамгийн хүйтэн өдрийг олдог програм.

Програм хоёр хэлбэрээр хийгдсэн:
- Flowgorithm блок схем
- C хэл (main.c)

## Зохиосон дүрмүүд

###  Оруулах утга

- Нийт 7 өдрийн температур оруулна. Өдөр бүрд нэг тоо.
- Хүчинтэй температур: *-50°C-аас 50°C хүртэл* (хоёр захын утга орно).
- Энэ мужаас гарсан утга оруулбал INVALID temperature гэж хэвлээд *дахин оруулуулна*. Буруу утга өдрийн тоонд тооцогдохгүй.
- Бутархай тоо зөвшөөрнө (жишээ нь -7.5). Цэгээр бичнэ, таслал ашиглахгүй.

###  Фаренгейт руу хөрвүүлэх томёо.

F = C * 9 / 5 + 32

###  Хүйтний ангилал ба хувцасны зөвлөмж

| Температур (°C) | Ангилал | Хувцас |
|---|---|---|
| 5 ба түүнээс дээш | Dulaahan (дулаахан) | Nimgen hurem (нимгэн хүрэм) |
| 0-ээс 5 хүртэл (5 орохгүй) | Seruuhen (сэрүүхэн) | Tsamts, hurem (цамц, хүрэм) |
| -10-аас 0 хүртэл (0 орохгүй) | Huiten (хүйтэн) | Uwliin kurtik, malgai (өвлийн куртик, малгай) |
| -20-оос -10 хүртэл (-10 орохгүй) | Mash huiten (маш хүйтэн) | Zuzaan kurtik, beelii, oroolt (зузаан куртик, бээлий, ороолт) |
| -20-оос доош | Tas huiten (тас хүйтэн) | Dulaan dawhar huwtsas, malgai, beelii, nooson umd (дулаан давхар хувцас, малгай, бээлий, ноосон өмд) |


###  Хамгийн хүйтэн өдөр

- Анх minTemp = 999, coldDay = 0 гэж эхэлнэ.
- Өдөр бүр temp < minTemp бол minTemp = temp, coldDay = i болгоно.
- Шалгалт нь *хатуу жижиг* (<) тул хоёр өдөр адил хүйтэн бол *эхний өдрийг* авна.

### 5. Гаралт

Өдөр бүр:

<temp>C = <fahrenheit>F, <category>, <clothes>

7 өдрийн дараа:

Hamgiin huiten udur: <coldDay>
Hamgiin baga temp: <minTemp>C

### Flowgorithm

1. Flowgorithm дээр блок схемээ нээнэ.
2. Run (F5) дарна.
3. Console дээр тоо бүрийг *нэг нэгээр* бичээд Enter дарна. Таслалаар нэг мөрөнд бичиж болохгүй.

### C

gcc main.c -o main
./main

Windows дээр main.exe гэж ажиллуулна.

C код температурыг нэг оронтой (-30.0C) хэвлэнэ. Flowgorithm -30C гэж хэвлэнэ. Утга нь адилхан, зөвхөн хэлбэр өөр.
